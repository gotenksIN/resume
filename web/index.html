Video Subtitler ↗

Python · Gemini API · FFmpeg · Pydantic

Four-pass CLI that generates English WebVTT subtitles from video.

  • Runs Pass 0 search grounding for speaker names and terms in parallel with chunk splitting and audio extraction.
  • Repairs chunk-boundary cutoffs against the full audio within [boundary ± 10s] using sparse-patch-v1 patches.
  • Resumes interrupted runs under an fcntl.flock work lock and publishes every output with atomic writes.
